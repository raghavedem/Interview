## 💡 TIPS FOR SUCCESS

### During Interview
1. **Clarify questions** - "Do you mean...?"
2. **Think out loud** - Explain your approach
3. **Ask for hints** - "Is it okay if I assume...?"
4. **Consider trade-offs** - "This uses more memory but..."
5. **Mention edge cases** - "What about empty input?"

### In Answers
1. Start with "why" - Why would you use this?
2. Explain with examples - Show code
3. Discuss alternatives - Other approaches?
4. Mention trade-offs - Speed vs memory?
5. Real-world use - Where would you use this?

### General Strategy
1. Be confident - You've studied!
2. Be clear - Explain simply
3. Be honest - "I don't know, but..."
4. Be curious - Ask questions
5. Be enthusiastic - Show passion for Python
