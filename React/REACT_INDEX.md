## 💡 TOP 10 INTERVIEW QUESTIONS

1. **Difference between class and functional components?**
   → Functional: Simpler, hooks, recommended. Class: Older, lifecycle methods.

2. **What are hooks and why use them?**
   → Reuse logic, manage state in functional components. useState, useEffect, etc.

3. **Explain useState and useEffect.**
   → useState: State management. useEffect: Side effects, cleanup, lifecycle.

4. **What's the Context API?**
   → Pass data deep without prop drilling. Global state like auth, theme.

5. **How to optimize React performance?**
   → React.memo, useMemo, useCallback, code splitting, lazy loading.

6. **Explain the key prop in lists.**
   → Unique identifier. Helps React track changes. Don't use index.

7. **How to test React components?**
   → Jest for unit tests. React Testing Library for component tests.

8. **What's TypeScript and why with React?**
   → Type safety, catch errors early, better IDE support, self-documenting.

9. **Explain controlled vs uncontrolled components.**
   → Controlled: Value from state. Uncontrolled: Value from DOM.

10. **How to handle forms in React?**
    → useState for inputs, onChange handlers, onSubmit for submission, validation.
